# 硬件比价工作台（pricewatch）

抓 **淘宝 / 京东 / 拼多多** 的 **DDR4、DDR5 内存** 和 **RTX 50 系显卡** 价格，
本地网页界面，自动区分类别、一手/二手，过滤假货和离谱价格，每天定时跑。

> 纯本地运行，数据存在 SQLite，不外传。仅供个人比价参考。

---

## 快速开始

```bat
python -m pip install -r requirements.txt
python run.py
```

或双击 **`启动.bat`**。浏览器打开 **http://127.0.0.1:8765**

第一次用必须在界面里点各平台的「登录 / 扫码」（详见第五节）。

## 一、它解决什么问题

### 问题 1：一个标题挂多个规格

```
铭瑄DDR5 6000 16G内存条32G海力士A-die暗耀D5机甲暴风瑷雪16G*2
  → 实际挂 11 个规格：¥489 的 DDR4 8G 到 ¥4088 的 DDR5 16G*2
```

列表页只显示**最低那个规格**的价格。只按标题比价，误差能到 8 倍。

**解法**：进商品详情页解析内嵌 SKU JSON（`skuBase.skus` + `skuCore.sku2info`），
拿到全部规格的真实价格。界面每行有「看规格」按钮。

### 问题 2：假货和离谱价格污染最低价

```
¥69   拆机DDR4台式机内存条4G 8G 2133 2400 2666 四代全兼  [安信精品硬盘批发]
¥365  16g内存条8G DDR4 32G ddr5 笔记本内存台式电脑内存    [电码堡]
¥920  议价议价宏基ddr5 16g*2 6000 c32一起32g             [永赢工控]
```

这些不筛掉，整张表就不可信。

**解法**：三级过滤 —— 假货指纹直接剔除，价格离群单独列出，二手单独一档。

### 问题 3：一手和二手混在一起

二手 8G DDR5 ¥300，全新 ¥700。混在一起时最低价永远是二手，一手价就看不见了。

**解法**：`condition` 字段（new/used）独立，分类键里带「二手」后缀，价格分开统计。

## 二、三级过滤

| 档 | 判定 | 处置 | 界面 |
|---|---|---|---|
| **正常** | 通过全部检查 | 收录 | 默认显示 |
| **异常** | 同档价格离群 | 收录但标记 | 「异常清单」页 |
| **剔除** | 假货指纹命中 | **不入库** | 「已剔除」留档 |

### 第一级：假货指纹

打分制，**≥4 分剔除**：

| 检测项 | 分值 | 说明 |
|---|---|---|
| 标题含非商品词 | **5** | 配件/支架/空盒/定金/**议价**/差价链接/测试链接 |
| 标题堆砌互斥规格 | 2/项 | 同时写 DDR4+DDR5、台式+笔记本、堆 3 种容量、堆 4 种频率 |
| 价格异常 | 3 | 低于同类中位数 45% |
| 店名通用 | 2 | 正品XX经销商 / 中国XX供应商 / tb+数字 / XX批发 |
| 标题无品牌 | 1 | 一个品牌名都没有 |

**关键取舍**：有品牌 + 店名正常时，多容量列表**不扣分** ——
正规商家挂多规格是淘宝的常规做法。这条把误杀率从 12% 降到 5%。

### 第二级：价格离群

不在全站比，**只在同档位内比**：「DDR5 16G 台式 6000」这一档里 ¥4799 就是异常。

三种判定法，按样本量自动选：

1. **IQR 法**（样本 ≥4）：Q1-1.5×IQR ~ Q3+1.5×IQR 之外算离群
2. **中位数倍数**（样本 2-3）：低于中位数 40% 或高于 3 倍
3. **行业基准价**（样本 <2）：`outlier.BASELINE` 内置 28 个规格的合理区间

低得离谱 → 剔除；高得离谱 → 标记（旗舰型号确实贵，不能一刀切）。

### 第三级：二手单独一档

```
分类「DDR5 16G 台式 6000」（一手）
分类「DDR5 16G 二手」        （二手）
```

判定词：二手/拆机/拆解/翻新/矿卡/9成新/99新/散片/回收/退役/成色

## 三、分类维度

| 维度 | 拆法 | 例子 |
|---|---|---|
| 代数 | DDR5 / DDR4 | |
| 单条容量 | 4G/8G/16G/32G/64G 各自独立 | `DDR5 8G 台式` |
| 套装条数 | 明确标 ×N（**不等于总容量**） | `DDR5 16G×2 台式` |
| 频率档 | ≤4800/5200/5600/6000/6400/7000/7600+ | `DDR5 16G 台式 6000` |
| 台式/笔记本 | 独立 | `DDR5 16G 笔记本` |
| 显卡 | 型号 + 显存 | `RTX 5070 Ti 16G` |
| 成色 | 一手/二手 | 二手加「二手」后缀 |

归一结果：**315 件 → 64 个分类**。

## 四、界面

### 四个视图

| 视图 | 内容 |
|---|---|
| **分类比价**（默认） | 每个规格一行：最低价 / 最高价 / 差价 / 件数 / 最低价商品链接 |
| **商品明细** | 每件一行：成色 / 规格 / 现价 / 历史最低 / 店铺 /「看规格」按钮 |
| **异常清单** | 价格离群的单独列出，带异常原因 |
| **已剔除** | 可疑商品留档，方便回看调规则 |

### 筛选控件

- 分类 / 平台下拉
- **成色**：全部 / 仅一手 / 仅二手（默认仅一手）
- **含异常**：勾上则异常条目一起显示
- 搜索框：标题 / 店铺
- 导出 CSV

## 五、三平台登录

| 平台 | 方式 | 说明 |
|---|---|---|
| 淘宝 | 扫码 | 手机淘宝扫窗口里的二维码 |
| 京东 | 扫码或账号 | 京东 App 扫码 |
| 拼多多 | **只能手机号 + 验证码** | 网页版没有扫码入口（拼多多自身限制） |

点「登录 / 扫码」→ 弹出浏览器 → 扫码 → **程序每 3 秒自动检测，成功就关窗并自动继续采集**。

登录态存在 `data/profiles/<平台>/`，下次开程序不用重登（几天到几周有效）。

## 六、降低平台风控

| 措施 | 说明 |
|---|---|
| 用本机 Edge 真内核 | 而非 Playwright 自带 chromium |
| 抹掉自动化标记 | `--enable-automation` / `navigator.webdriver` / `window.chrome` |
| 持久化 profile | 攒真实浏览历史和 cookie |
| 站内 Referer | 从首页点进搜索，不是直接敲 URL |
| 节奏随机化 | 首屏 1.8–3.2s、滚动 700–1500px、关键词间 3–7s、平台间 6–13s |
| 首页预热 | 先进站待 2–3.6s，滚一下，再搜索 |
| 绝不并发 | 三平台串行 |

`config.py` 里 `GENTLE = True` 是总开关，`SCHEDULE_TIME = "21:40"` 避开日间风控巡检。

被限流（京东「访问频繁」）会识别出来并冷却 10 分钟，不会越撞越狠。

## 八、工具脚本

| 脚本 | 用途 |
|---|---|
| `tools_analyze_patterns.py` | **从真实数据归纳共同点**：规格组合分布、价格跨度、品牌覆盖率、高频词；`--write` 导出基准价 |
| `tools_rebuild.py` | **存量重算**：改规则后不用重抓，重算分类和过滤；`--apply` 写库 |
| `tools_verify.py <平台> <关键词>` | 单平台单关键词真实采集验证 |
| `tools_item_sku.py <平台> <ID>` | 进详情页看 SKU |
| `tools_sniff.py` / `tools_sniff_post.py` | 抓包分析接口（找出数据从哪来） |
| `tools_probe_pages.py` | 存页面快照用于离线调选择器 |

### 共同点归纳

```bash
python tools_analyze_patterns.py
```

实测输出：
```
代数    容量  条数  类型   件数    最低    中位    最高   跨度
DDR5    16    1   台式    39  ¥645  ¥1585  ¥4799  7.4x
DDR4     8    1   台式    36  ¥ 69  ¥ 237  ¥1323 19.2x
DDR5    16    2   台式    20  ¥369  ¥1770  ¥4420 12.0x
品牌覆盖率: 82%    二手占比: 6.7%
```

`DDR4 8G 台式` 跨度 19 倍的原因：标题挂「8G 16G 32G」，实际卖的是 16G，
但列表页价格对应 16G。**这是列表页的固有局限，只能靠详情页 SKU 或离群检测补。**

## 十、常见问题

**界面打不开** — 端口被占，改 `config.py` 的 `PORT`

**解析不到商品** — 看 `logs/diag_<平台>_<时间>.txt`（记录了选择器命中数、真实价格节点 DOM 链）和整页 HTML

**数据混进奇怪的东西** — 调 `fakefilter.py`：`FAKE_WORDS` 加词，`if ratio < 0.45` 调价格门槛，`points >= 4` 调判定分

**想清空重来** — 删 `data/pricewatch.db`（登录态在 `data/profiles/` 不受影响）

**价格是券后价还是标价** — 列表页展示价，通常就是券后价，不含运费和满减

**被限流了** — 京东对搜索频次敏感，等 10 分钟再跑；程序已识别并自动冷却
